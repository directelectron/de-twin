de_twin.column.Column#

class de_twin.column.Column(state=None, *, clock=None, instrument_type=None, allow_ht=False, stage_speed_um_s=100.0, tilt_speed_deg_s=10.0, stage_limits=(2000.0, 2000.0, 500.0, 70.0, 30.0), corrector=None, seed=0, corrector_options=None)[source]#

Bases: object

A simulated column. Thread-safe (self.lock is an RLock).

Parameters:

  • state (Optional[MicroscopeState]) – Initial state (defaults: MicroscopeState defaults, i.e. 200 kV, MAG1 20 kx, screen up so the camera sees the beam).

  • clock – Callable returning seconds, or an object with now() (de_twin.clock.Clock). Stage motion is interpolated on this clock; a virtual clock fast-forwards it.

  • instrument_type (Optional[str]) – Vendor string reported as INSTRUMENT_Type (“JEOL” default, or “FEI”).

  • allow_ht (bool) – Permit high-tension / filament writes (refused by default).

  • stage_speed_um_s (float) – Stage dynamics; stage_speed_um_s=float('inf') makes moves instantaneous.

  • tilt_speed_deg_s (float) – Stage dynamics; stage_speed_um_s=float('inf') makes moves instantaneous.

  • stage_limits (Iterable[float]) – Stage dynamics; stage_speed_um_s=float('inf') makes moves instantaneous.

  • corrector (Optional[str]) – None / "none" (default; or state.corrector), "probe", "image" or "both": fit a CEOS-like aberration corrector (self.corrector).

  • seed (int) – Seeds the corrector’s native aberrations, tune, drift and noise.

  • corrector_options (Optional[dict]) – Extra keyword arguments for Corrector (tuned=False for a cold start, drift_rates={...}, served="image").
