EBSD frames render in one fused, threaded numba pass that hands the detector its Poisson means (``Detector.expose(means=)``), from a cube-map copy of each master pattern: ~1800 / 1400 / 735 camera frames/s at 128² / 256² / 512² (was ~1200 / 970 / 300). The default ``EbsdGeometry.band_contrast`` is now 0.06 (raw bands ~10 % above the background, as measured), and bulk specimens darken a ~0.2 µm zone along grain boundaries.
