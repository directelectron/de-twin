de_twin.column.corrector.Corrector#

class de_twin.column.corrector.Corrector(kind='probe', *, clock=None, seed=0, tuned=True, ht_kv=200.0, lock=None, drift_rates=None, drift_step_s=1.0, operator=None, beam_check=None, label=None, served=None, sleeper=None)[source]#

Bases: object

Probe and/or image corrector of a column.

>>> col = Column(corrector="probe", seed=1, clock=ManualClock())
>>> col.corrector.pi4_angle_mrad()          # ~25-30 mrad when tuned
>>> r = col.corrector.measure("Standard")   # tableau; advances a ManualClock
>>> col.corrector.correct("B2"); col.corrector.correct("A2", fraction=0.7)

kind is "probe", "image" or "both". served is the side the DE-TEM-Channel face serves (the channel keeps one endpoint; the probe corrector by default). Every method takes side= to address the other one in-process.
